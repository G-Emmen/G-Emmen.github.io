NASA Exoplanet Watch - Citizen Science

Contributor to NASA’s Exoplanet Watch program, turning raw telescope images into transit light curves that refine exoplanet orbital timing. I built a locally hosted web application around the EXOTIC reduction pipeline that ingests raw MicroObservatory and checked-out .FITS data, automates star chart coordinate matching with user confirmation, and produces publication-ready light curve charts. All results are published to the AAVSO Exoplanet Database under observer code EGRA.

Stack: Python, Pandas, EXOTIC Reduction Analysis

Regenerative Braking Control Method

Analysis of six-switch inverter control strategies for recovering braking energy with a brushless DC motor. I built an electromechanical model in MATLAB/Simulink and used it to compare inverter switching approaches for regenerative braking.

Stack: MATLAB, Simulink, SimScape

Satellite Attitude Control System

Design and analysis of a PID-based attitude controller for orienting a satellite relative to a reference. The study compares open- and closed-loop response and evaluates the controller’s stability and noise rejection.
